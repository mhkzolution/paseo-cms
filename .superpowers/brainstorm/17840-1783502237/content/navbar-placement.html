Homepage navbar ควรอยู่ตรงไหน?

หน้าแรกจะมีเมนู anchor ไปแต่ละ section — เลือกรูปแบบที่ชอบ

A

แทนที่ Site Header ทั้งหน้า

หน้าแรกใช้แค่ navbar section (กิจกรรม / บทความ / Introduction …) ไม่มีเมนูสำรวจ One Bangkok แบบหน้าอื่น

B

Site Header + Section Navbar ซ้อน

เก็บเมนูสำรวจ/โลโก้/โซเชียลเหมือนเดิม แล้วมีแถบเมนู section sticky ด้านล่างหรือทับ hero

C

Site Header เบา + Section Navbar เป็นหลัก

แถบบนเหลือโลโก้/ค้นหา/โซเชียลสั้นๆ ส่วนเมนูหลักของหน้าแรกคือ section links
